TaskPet

Cuidado inteligente y centralizado para tus mascotas

Nunca más olvides una vacuna, cita o desparasitación

TaskPet es una aplicación web progresiva (PWA) diseñada para dueños de mascotas que necesitan un control confiable de la salud y el bienestar de sus animales.

¿Qué resuelve TaskPet?

📅

Recordatorios inteligentes

Alertas de vacunas, controles veterinarios y desparasitaciones.

📋

Historial clínico

Toda la información de salud de tu mascota en un solo lugar.

🛒

Control de stock

Seguimiento de alimento y gastos veterinarios.

Sobre el proyecto

Microempresa: TaskPet (PetCare Solutions)
Propuesta: Aplicación Web Progresiva (PWA) + API RESTful
Tecnologías: Frontend (React/Vue) · Backend (Python FastAPI/Django) · PostgreSQL

Integrante: Andry Gisella Buitrago García
